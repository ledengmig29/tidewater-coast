# 海岸 · 潮汐之间

全屏实时海岸：海浪涌向沙滩，碎浪形成白沫，退水留下湿沙与泡沫。紧凑沙岛上是一座夏威夷木屋，带蓝绿木板外墙、奶油色窗框、珊瑚红坡屋顶、架高木地板、露台、台阶、吊床、冲浪板、座椅和盆栽。房屋周围布置 6 棵棕榈、8 棵铁树和 12 组花草；房屋、道具及植物使用原生三维网格。

屋前浅滩保留 15 只粉色水母，收缩伞体并摆动口腕与触须，沿各自的小范围轨迹游动。楼梯下方及两侧布置 10 只寄居蟹，带螺壳、双螯、眼柄和交替爬动的腿，沿沙面缓慢移动。动物全部使用原生三维网格；水母的透明材质也进入水下折射绘制。海龟与魔鬼鱼已移除。

当前首页已替换“一束光”展览，使用 [Tidewater](https://dgreenheck.github.io/tidewater/) 的 MIT 开源海岸代码，保留四级联 FFT 海浪、近岸波、冲滩模拟、沙地、折射、焦散、大气与体积云。本轮修正此前土堆般的地形，沙面最高约为海平面上方 0.61 m，岸坡放缓，没有山体和岩石。按地形采样函数的海平面边界积分，总干沙面积约为 368.44 m²；扣除房屋加露台投影并集 122.1 m² 后，屋外露沙约为 246.34 m²，是房屋与露台占地的 2.018 倍。重叠区域只计一次，屋下沙地不计入露沙指标，岸线采样随地形重新计算。

这是可自由移动的海岸与房屋环境查看器；当前未包含史迪仔或其他人物模型、人物动画、房屋内部场景，以及原作的钓鱼、船只、村庄和声音。上游源码固定于 `4811ba48d795197de5621985f404e765c0b7c0ef`，来源及完整授权见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 手动运行

```powershell
npm install
npm run dev
```

由用户手动运行并打开终端给出的地址。开发工作默认在后台进行，不自动启动 `npm run dev` 或打开浏览器、编辑器和预览面板。

页面需要能成功取得 WebGPU 设备的浏览器、硬件和驱动环境。可使用支持 WebGPU 且启用硬件加速的 Chrome / Edge，通过本地开发地址或 HTTPS 访问。首次加载会构建地形、加载本地云噪声、编译着色器并预热渲染；进度按初始化阶段更新，不代表剩余秒数，编译阶段可能停留较久。无法启用 WebGPU 或设备丢失时显示错误与重新加载按钮；当前没有 WebGL 或静态图片渲染回退。

## 操作

| 操作 | 效果 |
| --- | --- |
| 岸边 / 木屋 / 浅滩 / 俯瞰 / 水线 | 切换海边全景、房屋近景、浅海动物、俯瞰与贴近水面的位置 |
| 鼠标拖动、单指滑动 | 环顾四周 |
| 滚轮 | 沿视线前后移动 |
| W / A / S / D | 前后、左右移动 |
| Q / E | 下降、上升；按住 Shift 加速 |
| 暂停 / 继续 | 同步暂停或继续海浪、日光与动物；仍可移动、切换视角与调整光照 |
| 重播 30 秒 | 从日出重新播放到日落，并解除暂停 |
| 导出 30s | 制作并下载固定岸边镜头的 30 秒、1080p、60 fps MP4 |
| 设置 | 调整时间、浪势、亮度与画面精度 |

默认在 30 秒可见播放时间内从约 05:49 日出推进到约 18:11 日落，结束后保持日落光照，海浪与动物继续运动。日出和日落时刻由当前太阳轨迹与地平线交点计算。暂停会冻结日光进度；页面隐藏时不累计时间。手动拖动时间滑块会停止自动推进；“重播 30 秒”从日出重新播放。浪势范围为 0.4—1.5 倍。流畅、均衡、精细分别使用 0.6、0.8、1.0 的内部渲染比例，并调整云分辨率；默认均衡。恢复按钮重置岸边位置、日出、亮度与浪势，保留当前画面精度和暂停状态。

点击“浅滩”查看海洋动物，点击“木屋”后可向楼梯靠近查看寄居蟹。桌面与竖屏使用不同的浅滩观看位置；手机上的五个视角按钮按可用宽度换行。

系统启用“减少动态”时，加载完成后默认暂停海浪、日光与动物并关闭界面过渡。页面转入后台时停止动画循环，回到前台时恢复循环并保留暂停状态。设置可用 Escape 关闭；原生按钮、滑块和下拉框保留键盘操作，移动快捷键不在这些控件获得焦点时触发。

## 导出视频

用户手动启动项目后，点击右上角“导出 30s”。导出复用本场景完整渲染链，固定岸边镜头为 1920×1080，按 60 fps 制作 1800 帧，包含日出与日落两端。渲染使用持久后处理纹理读取，Mediabunny 调用浏览器的 H.264 编码并封装 MP4；不录制界面，不加字幕或声音。导出先预热日出光照，并核对编码帧数。完成后下载 `coast-sunrise-to-sunset-30s-60fps.mp4`，设置中也保留再次下载链接。

视频播放时长为 30 秒，制作耗时取决于显卡、编码能力与画质，不承诺在 30 秒内完成制作。期间请保持页面可见且不改变窗口尺寸；这些操作或设备错误会中止本次导出并恢复观看状态。浏览器或设备不支持此 H.264 编码配置时显示原因，不提供不完整的视频。

## 工程与检查

- `index.html` 加载 `src/coast-main.js`；`src/coast.css` 定义中文操作层。
- `src/tidewater/CoastalApp.js` 组装上游本地 WebGPU 引擎、海岸与房屋模块，`public/tidewater/` 保存云噪声与 SMAA 查找图。
- 依赖清单保留 Three.js 0.180.0 和 Vite 7.1.7；海岸使用随源码引入的原生 WebGPU 引擎。Mediabunny 1.56.1 仅在导出时加载，用于 H.264 编码与 MP4 封装。
- [PRODUCT.md](PRODUCT.md) 记录产品边界，[DESIGN.md](DESIGN.md) 记录当前界面设计。

```powershell
npm run check
npm run build
```

`check` 验证入口依赖与本地资源、地形采样和法线、沙面高度及岸坡、房屋之外的露沙面积、陆海边界、海岸传播场、CPU 海岸场保留及波向缓存；也检查木屋几何数据、两层房屋尺寸、网格批次、支柱接地，以及庭院植物数量、位置与根部接地。动物检查覆盖数量、有效法线、网格预算、暂停与时间重现，采样 0—300 秒的实际顶点，检查海底、平均水面、干沙和实体台阶的接触关系；使用模拟绘制接口验证透明水母的折射绘制保留海底颜色与深度。它不执行 GPU 渲染。`build` 生成生产资源。

本轮水母场景与 30 秒光照代码通过 `npm run check` 与 `npm run build`。水母为 45 个网格、122,100 个顶点；寄居蟹为 60 个网格、36,510 个顶点，共享物种几何。检查采样中水母最高点低于平均水面约 0.206 m，离海底至少约 0.383 m；寄居蟹没有穿过沙面或实体台阶。日光检查覆盖实际太阳地平线交点、15 秒正午、30 秒日落、暂停、重播与手动选择；视频参数检查为 1800 帧、60 fps、1080p。这不等同于实际渲染或视频编码验证。

此前本地预览访问被自动安全审核以 URL 协议策略为由拒绝，本轮未进行浏览器验证或实际视频导出，当前没有生成可交付的海岸 MP4。导出流程需要用户手动运行验证。未获取修复后的截图，也未验证当前 WebGPU 画面或运行时着色器。用户上传的截图记录修复前的土堆；上方预览保留此前海浪与沙滩的实际截图，不含当前木屋、庭院及动物。
